# Math Page Vision Lab

Учебное приложение для распознавания одной страницы математического учебника. Загрузите JPG, PNG или PDF, выберите страницу PDF, посмотрите предпросмотр и нажмите **«Распознать страницу»**. Результат можно изучить на экране и скачать как Markdown или JSON.

Сайт открыт всем без регистрации. Он не определяет, кто является участником курса. Каждый запуск распознавания обращается к OpenAI API и может расходовать платный лимит.

## Как устроен проект

- `app/` — интерфейс на Next.js: проверка файла, предпросмотр PDF через PDF.js, показ результата и скачивание файлов.
- `api/recognize.py` — один серверный HTTP endpoint `/api/recognize` для Vercel Python Runtime.
- `python/` — проверка файлов и ответа модели, преобразование выбранной страницы PDF в изображение, формирование Markdown.
- `requirements.txt` и `.python-version` — зависимости и версия Python для локального запуска и Vercel.
- `.env.example` — образец конфигурации без секретов.

Ограничения: файл до **3 МиБ** (3 × 1024 × 1024 байт), только JPG/PNG/PDF, PDF от 1 до 100 страниц. Один запрос обрабатывает только выбранную страницу. Браузер отправляет серверу исходный файл и номер страницы; сервер преобразует выбранную страницу в JPEG и отправляет в OpenAI только это изображение. Файлы и результаты не хранятся на сервере после запроса. Результат в браузере исчезнет после перезагрузки страницы, поэтому при необходимости скачайте его.

## Локальный запуск на Windows (PowerShell)

Нужны Python 3.12, Node.js с npm и действующий ключ OpenAI API. Команды выполняйте **из корня проекта**. Откройте два терминала.

**Терминал 1 — Python API:**

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Откройте `.env` и заполните `OPENAI_API_KEY`. Команда выше сохраняет существующий `.env`. Затем запустите:

```powershell
python -m api.recognize
```

Python API будет слушать `http://127.0.0.1:8000`. Этот терминал оставьте открытым.

**Терминал 2 — веб-интерфейс:**

```powershell
npm ci
$env:LOCAL_PYTHON_API = 'http://127.0.0.1:8000'
npm run dev
```

Откройте `http://localhost:3000`. Переменная `LOCAL_PYTHON_API` задаёт локальный адрес Python API для перенаправления `/api/recognize` в режиме разработки. При перезапуске терминала задайте её заново. Для остановки процессов нажмите `Ctrl+C` в обоих терминалах.

Если PowerShell запрещает запуск `Activate.ps1`, можно не активировать окружение и запускать команды через `.\.venv\Scripts\python.exe`, например `.\.venv\Scripts\python.exe -m api.recognize`.

## Локальный запуск на macOS/Linux

В первом терминале, из корня проекта:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
test -f .env || cp .env.example .env
# Впишите OPENAI_API_KEY в .env
python -m api.recognize
```

Команда копирования сохраняет существующий `.env`. Во втором терминале:

```bash
npm ci
LOCAL_PYTHON_API=http://127.0.0.1:8000 npm run dev
```

Откройте `http://localhost:3000`.

## Конфигурация

| Переменная | Где нужна | Значение |
| --- | --- | --- |
| `OPENAI_API_KEY` | Python локально и Vercel | Секретный ключ отдельного проекта OpenAI. Обязательна для распознавания. |
| `OPENAI_BASE_URL` | Python локально и Vercel | По умолчанию `https://api.openai.com/v1`. Иной сервис должен поддерживать Responses API, изображения и структурированный вывод. |
| `OPENAI_MODEL` | Python локально и Vercel | По умолчанию `gpt-6-luna`. Модель должна поддерживать изображения и структурированный вывод. |
| `LOCAL_PYTHON_API` | Только локальный процесс Next.js | Адрес локального Python API. **Не задавайте в Vercel.** |

`.env` загружается локальным процессом Python. Next.js не нужен доступ к ключу. Файл `.env` исключён из Git; не вставляйте ключ в исходный код и не используйте для него префикс `NEXT_PUBLIC_`. На Vercel задайте серверные переменные через панель проекта.

## Публикация на Vercel

1. В Vercel выберите **Add New → Project**, подключите GitHub и импортируйте `mytrainee-ai/Math_consultations`.
2. Оставьте **Framework Preset: Next.js** и **Root Directory: `./`** (корень репозитория). Python Function лежит в `api/recognize.py`; Vercel берёт Python 3.12 из `.python-version`, а зависимости — из `requirements.txt`.
3. До развёртывания добавьте в **Settings → Environment Variables** `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL` для окружения **Production**. Для проверки Preview-развёртываний добавьте их и в **Preview**. Значения ключа не должно быть в Git. Если меняли переменные после сборки, выполните **Redeploy**.
4. Запустите **Deploy**. На опубликованном URL проверьте загрузку PNG, PDF, выбор другой страницы, распознавание, вкладки Markdown/JSON и скачивание. При ошибках смотрите логи функции `/api/recognize` в Vercel.
5. Перед открытием ссылки для аудитории настройте ограничения расходов, описанные ниже.

В продакшене Next.js и Python Function работают на Vercel в одном проекте. Локальная переменная `LOCAL_PYTHON_API` там не требуется.

## Ограничение расходов публичного сайта

Публичный endpoint `/api/recognize` может вызывать любой посетитель. В Vercel откройте **Project → Firewall → Configure → New Rule** и создайте правило для метода `POST` и пути `/api/recognize` с действием **Rate Limit**. Практический стартовый порог — около 10 запросов в минуту на IP; проверьте его на занятии и скорректируйте, если много студентов используют один общий IP. Сохраните правило, затем **Review Changes → Publish**; проверьте в Firewall, что оно опубликовано. На тарифе Hobby доступно одно правило rate limiting на проект. [Документация Vercel Firewall](https://vercel.com/docs/vercel-firewall/vercel-waf/rate-limiting).

В OpenAI создайте отдельный проект и ключ именно для этого сайта. В настройках проекта **Limits** задайте небольшой **Monthly spend limit** и включите **Enforce a hard limit**; уведомления о расходах можно добавить отдельно. Следите за Usage после первого занятия. Ограничения частоты и бюджета снижают расходы, но не подтверждают личность посетителя и не дают абсолютной защиты от распределённого трафика или задержки в учёте расходов. [Управление проектами и лимитами OpenAI](https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform), [безопасность ключей](https://help.openai.com/en/articles/5112595-best-practices-for-api-key-safety).

## Формат результата

Ответ API содержит `result` (проверенный JSON), `markdown`, имя модели и статистику токенов, если её вернул провайдер. `document.language` — краткий код языка, например `ru`, `en` или `und`. Формулы в JSON хранятся как LaTeX без `$`. Таблицы сохраняются **по ячейкам** в `rows`, а `has_header` показывает, является ли первая строка заголовком:

```json
{
  "type": "table",
  "rows": [["x", "y"], ["1", "2"], ["2", "4"]],
  "has_header": true
}
```

Markdown формируется на сервере из проверенного JSON без второго запроса к модели. Это учебное распознавание: сложная вёрстка, формулы и таблицы могут требовать ручной проверки.

## Если что-то не работает

- **Страница открывается, но запрос не проходит локально:** проверьте, что Python API запущен в первом терминале, а `LOCAL_PYTHON_API` задан во втором до `npm run dev`.
- **«Ключ OpenAI не настроен»:** заполните `OPENAI_API_KEY` в `.env` внутри проекта или в переменных Vercel. После изменения перезапустите Python API или выполните Redeploy.
- **Ошибка модели или авторизации:** проверьте `OPENAI_MODEL`, ключ и доступ выбранного проекта OpenAI к модели. Альтернативный `OPENAI_BASE_URL` должен поддерживать нужные возможности Responses API.
- **Файл отклонён:** проверьте формат, размер до 3 МиБ и отсутствие пароля у PDF. Повреждённый PDF или изображение нужно заменить.
- **Ошибка 429:** проверьте лимиты Vercel Firewall и OpenAI. Для группы за одним IP может понадобиться иной порог.

Требования и принятые решения подробно описаны в [PRD_VERCEL.md](PRD_VERCEL.md). Условия обработки отправленного изображения определяются выбранным API-провайдером.
